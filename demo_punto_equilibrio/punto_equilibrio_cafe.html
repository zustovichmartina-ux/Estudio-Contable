Cómo entran las ventas

Paso 1

Exportar del sistema

Desde el sistema de gestión se baja el detalle de ventas a CSV o Excel. Si tiene API, este paso es automático.

Paso 2

Subir el archivo

La herramienta reconoce las columnas de fecha, producto, cantidad e importe y arma el mes.

Paso 3

Se recalcula todo

Semáforo, proyección, costeo y aviso se actualizan con los números reales.

Formato esperado (separador ; o ,):

fecha;producto;cantidad;total
21/11/2026;Cortado;38;144400
21/11/2026;Medialuna;85;127500

Así llegó el archivo

La herramienta usa fecha, artículo, cantidad e importe. Las demás columnas se ignoran.
